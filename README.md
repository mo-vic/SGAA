# Sigmoid–G Alternating Activation (SGAA)

A research study of a hyperparameter-free activation scheme built from the
logistic sigmoid and the antiderivative of its reciprocal derivative.

## The idea

For the logistic sigmoid `σ(x) = 1/(1+e^{-x})` with `σ'(x) = σ(x)(1-σ(x))`, define
the antiderivative of the *reciprocal* derivative

```
G(x) = ∫ 1/σ'(x) dx = e^x - e^{-x} + 2x = 2 sinh(x) + 2x,
```

so that `G'(x) = 1/σ'(x)`. If a network alternates `σ` and `G` as its hidden
activations, adjacent layers contribute

```
σ'(z_i) · G'(z_{i+1}) = σ'(z_i) / σ'(z_{i+1})
```

to the backprop signal. **When the two pre-activations are similar the product
is ≈ 1**, so it can neither vanish nor explode — unlike the all-`σ` case, where
the product `σ'(z_i)·σ'(z_{i+1}) ≤ 1/16` is small and gradients vanish with depth.

## Key results (MNIST)

| scheme | best test acc | grad-ratio @ init | act-max |
|--------|--------------:|------------------:|--------:|
| all-σ  | 0.972         | 3.37 (vanishing)  | 1.0     |
| **σ/G alt** | **0.974** | **1.03 (balanced)** | 1e2  |
| G/σ alt | 0.191         | ∞ (explodes)      | 5e11    |
| ReLU   | 0.977         | 0.74              | 13      |
| tanh   | 0.976         | 0.79              | 1.0     |

Alternating σ/G keeps the input-to-output gradient ratio at ≈ 1 from
initialisation, beats all-σ, and extends the trainable depth roughly two-fold.
The order matters: starting with `G` (`G/σ`) explodes the activations. The
unbounded forward growth of `G` imposes a depth ceiling.

## Quick start

```bash
# install the package (optional; you can also set PYTHONPATH=src)
pip install -e .

# verify the mathematics / identities
python -m sgaa verify

# run the experiments (needs a local MNIST; see caveat below)
python -m sgaa experiments

# regenerate the figures and print the summary tables
python -m sgaa figures
python -m sgaa analyze

# the whole pipeline in one shot
python -m sgaa run-all          # or ./scripts/run_all.sh
```

The command-line entry point is equivalent for each sub-command:

| command                  | action                                      |
|--------------------------|---------------------------------------------|
| `python -m sgaa verify`    | verify σ', G' and the σ'/G identity      |
| `python -m sgaa experiments` | run the main comparison + depth sweep   |
| `python -m sgaa figures`    | rebuild all figures from `results/`      |
| `python -m sgaa analyze`    | print headline summary tables            |
| `python -m sgaa run-all`    | verify → experiments → figures → analyze |

## Reproducing the paper

cd paper && pdflatex sgaa_paper.tex && pdflatex sgaa_paper.tex

## Environment

* Ubuntu 22.04, Python 3.12, PyTorch 2.12.1+cu130, NVIDIA RTX 3080 Ti.
